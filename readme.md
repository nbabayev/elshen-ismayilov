# Elshan Ismayilov - Fullstack Web Application (Work In Progress 🛠️)

A modern fullstack web application built with Next.js, React, and TypeScript. This project is currently **actively in development** and is being built with a focus on system architecture, robust state management, and optimized backend routing.

> ⚠️ **Note:** This project is a Work In Progress (WIP). Features are being added incrementally, and the architecture is being refined daily.

## ⚙️ Current Status & Progress

- **[In Progress]** System Architecture & Database layer integration using Sequelize ORM.
- **[In Progress]** Media Management with Cloudinary API.
- **[Next Up]** Authentication, secure session handling, and advanced route protection.
- **[Next Up]** Finalizing UI/UX responsiveness and performance optimization.

## 🛠️ Planned Tech Stack

- **Frontend:** React, Next.js (App Router), TypeScript, Tailwind CSS
- **Backend/ORM:** Next.js API Routes, Sequelize ORM
- **Services:** Cloudinary (for media optimization), Vercel (Deployment workflow)
